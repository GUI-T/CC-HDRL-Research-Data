
# CC-HDRL Research Data

This repository provides the test instances and research data associated with the paper:

**Communication Coverage-Constrained Hierarchical Deep Reinforcement Learning for Multi-UAV Data Collection**

## Contents

- `CC_HDRL_test_instances_500_v2.zip`: Test instances used in the experiments.

## Usage

Download the ZIP archive and extract the files to access the test instances.
